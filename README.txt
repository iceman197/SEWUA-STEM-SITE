SEWUA V2500
============

Run locally:
  python3 server.py
Then open:
  http://127.0.0.1:8080

Optional AI:
  Set GEMINI_API_KEY in the environment.
  Optional GEMINI_MODEL defaults to gemini-2.5-flash.

Examples:
  Linux/Termux: export GEMINI_API_KEY="YOUR_KEY"
  Windows PowerShell: $env:GEMINI_API_KEY="YOUR_KEY"

The frontend stores student preferences, notes, tasks, grades, quiz history and other local data in browser localStorage. The Python backend provides course/quiz APIs, activity logging and the AI endpoint.
